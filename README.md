Patrol Staffing Optimization using Operations Research

This project implements an optimization framework to allocate police patrol resources across districts and shifts based on historical demand. The model uses integer programming to minimize response-time risk and unmet demand while respecting staffing constraints.

Key capabilities:
• Demand modeling using CAD call data
• Optimization using OR-Tools
• Scenario simulation for patrol allocation
• Interactive Streamlit dashboard
• Dockerized deployment

Technologies:
Python, OR-Tools, Pandas, Streamlit, Docker
